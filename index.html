Sharp Ω(κ1/psil log(1/ε)) Lower Bound for Gradient Descent on Strongly Convex Objectives

Yuhan Ye

Version 0.4 · November 25, 2026

Read the PDF LaTeX source GitHub repository

Abstract

Altschuler and Parrilo [AP25a] showed that their silver stepsize schedule accelerates gradient descent (GD) on smooth strongly convex functions. To halve the error, it improves the classical O(κ) iteration bound to O(κ1/psil), where κ is the condition number and psil = log2(1 + √2). For nonnegative stepsizes, Liu and Ye [LY26] matched this bound up to a subpolynomial factor in κ.

In this paper, we prove that GD with any predetermined sequence of real stepsizes requires Ω(κ1/psil log(1/ε)) iterations in the worst case to reduce either the squared distance to the minimizer or function suboptimality by a factor ε. For 0 < ε ≤ 1/2, this matches the silver upper bound up to an absolute constant.

First posted November 24, 2026, for nonnegative stepsizes. The real-stepsize result first appeared November 25.
